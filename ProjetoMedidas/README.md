# Projeto: Tipos de Medidas em CSS

Este trabalho consiste em uma aplicação web interativa desenvolvida para apresentar e explicar os principais tipos de unidades de medida em CSS, abordando conceitos fundamentais de design responsivo e acessibilidade.

O projeto foi estruturado em formato de slides navegáveis, permitindo visualizar na prática como cada unidade funciona por meio de exemplos dinâmicos e demonstrações interativas.

## 📌 Conteúdo abordado

* Diferença entre **unidades absolutas e relativas**
* Uso de **px, em, rem, %**
* Unidades de viewport: **vw, vh, vmin, vmax**
* Unidades tipográficas: **ch e ex**
* Uso de **clamp()** para tipografia fluida
* Conversão entre unidades (px → rem)
* Comparações práticas e recomendações de uso

## 🛠️ Tecnologias Utilizadas

* **HTML5** – estrutura da aplicação
* **CSS3** – estilização e layout responsivo
* **JavaScript (ES6+)** – interatividade, navegação entre slides e cálculos dinâmicos

## ▶️ Como executar

1. Extraia o arquivo `.zip`
2. Abra o arquivo `index.html` em qualquer navegador
